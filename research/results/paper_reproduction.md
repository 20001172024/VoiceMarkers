## 2. How much one split can vary

Over 200 random unstratified 80/20 splits the notebook's linear SVM scores **86.03% ± 5.02%** test accuracy (5th–95th percentile 76.92% – 94.87%) and 77.39% ± 7.91% balanced accuracy. The paper's 87.18% is a typical draw from this range; a single split cannot pin accuracy down to better than several percentage points.

## 3. The protocol described in the paper's text

The paper's Section III describes a stratified split and an RBF-kernel SVM whose C and gamma were tuned by grid search with 5-fold cross-validation. The notebook instead used a linear kernel with default settings and an unstratified split. For comparison, the described protocol was run as written; the grid was not published, so a conventional one was fixed before running (`C` ∈ [0.1, 1, 10, 100], `gamma` ∈ ['scale', 0.01, 0.1, 1]).

| Setup | Model | Training accuracy | Test accuracy |
|---|---|---|---|
| Paper (Table I) / notebook | linear SVM, unstratified, seed 2 | 88.46% | 87.18% |
| Notebook's model over 200 splits | linear SVM, unstratified | 90.26% ± 1.55% | 86.03% ± 5.02% |
| Described, default settings (200 splits) | RBF SVM, stratified | 89.87% ± 1.13% | 87.86% ± 3.58% |
| Described, grid search (100 splits) | RBF SVM, stratified, tuned C and gamma | 99.84% ± 0.55% | 93.21% ± 2.98% |

The reported figures come from the notebook's linear SVM. Run as described, the tuned RBF SVM scores 93.21% ± 2.98% on the test set at row level, but this is still a row-level estimate (see M2).
