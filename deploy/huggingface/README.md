# VoiceMarkers API

Backend of [VoiceMarkers](https://github.com/20001172024/VoiceMarkers), a research and
education demo of voice-based Parkinson's disease detection with machine learning.

**Not a medical device.** It does not diagnose, screen for or rule out Parkinson's disease
or any other condition, and predictions on new recordings are not reliable.

Audio is processed in memory and never stored. API docs: [`/docs`](./docs).

This Space is deployed automatically from the GitHub repository; edit the code there.
